# War Thunder QA Portfolio
### Junior QA Engineer – Practical Game Testing Workflow

---

## Overview

This repository demonstrates a structured **Game QA workflow** applied to **War Thunder (PC)**.

The objective of this portfolio is to simulate a real QA environment by documenting testing activities using industry-style structure and developer-oriented communication.

### QA Activities Included

- Structured Bug Reporting (reproducible defects with evidence)
- Test Planning and Test Case Design
- Exploratory Testing Sessions
- Fix Verification based on Patch Notes
- Regression-style validation

### Testing Approach

Testing practices are based on core QA principles:

- Functional Testing
- Exploratory Testing
- Regression Testing
- Structured Bug Lifecycle
- Context-driven Game QA methodology
